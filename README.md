# Multiple-Linear-Regression-Modeling
▪ Developed and implemented multiple linear regression models to accurately predict annual insurance premiums within RStudio
▪ Applied 10-fold cross-validation to assess model stability and performance across full, stepwise, and subset regression approaches
▪ Conducted model selection with AIC, adjusted R², and RMSE metrics, identifying stepwise regression as the most effective method
▪ Performed residual and normality diagnostics to confirm linear regression assumptions and ensure the reliability of the final model
